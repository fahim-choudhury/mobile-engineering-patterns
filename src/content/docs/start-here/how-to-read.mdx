This book is for engineers who know one mobile stack well and want a working model of the others. You should be comfortable shipping an app on your own platform. You don't need to know any of the other four.

## Every chapter follows the same path

1. **The problem**, in terms any mobile engineer recognises.
2. **Why mobile makes it hard**: the constraints the OS, the stores or the device impose.
3. **The pattern**, described without reference to any one stack.
4. **The pattern in each stack**, as tabs. Pick your stack once and every page remembers it.
5. **Trade-offs and scale**: what changes with a large app or a large team.
6. **Sources**, with the versions they apply to.

Code samples are short and idiomatic. They exist to show the shape of a solution, so you can recognise it, review it or ask an agent for it.

## Version baseline (November 2026)

| Stack | Versions assumed |
| --- | --- |
| Android | Android 17 (API 37), Kotlin 2.4 |
| iOS | iOS 27, Xcode 27, Swift 6 language mode |
| React Native | React Native 0.88, Expo SDK 57+, Hermes V1 |
| Flutter | Flutter 3.50, Dart 3.14 |
| KMP / CMP | Kotlin 2.4 (2.5 in RC), Compose Multiplatform 1.12 |

When a chapter depends on a newer or older version, it says so next to the claim.
